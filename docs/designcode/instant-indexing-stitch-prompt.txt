Design the "Instant Indexing" admin page for RankKernel, a free WordPress SEO plugin. It controls the IndexNow feature, which tells participating search engines that a specific URL changed. It must look like the same product as the existing Redirects and 404 Monitor admin pages.

SECTION A: ABSOLUTE PROHIBITIONS. A previous generation of this page violated these, so read them as hard rules.

A1. NEVER render the IndexNow API key in any form. Forbidden and must not appear anywhere on the page: a key input field, a masked or blurred or partially hidden key, a read only key box, a copy key button, a show or reveal key toggle, a key length, a key prefix or suffix, a key file name, and a key file URL. The key file URL is forbidden because it literally contains the key. The page may state only whether a key is configured. Do not design any control whose purpose is to display, reveal, copy, or store the key in the browser.

A2. Do NOT invent a "Key in Meta" versus "Key in File" toggle or tabs. There is exactly one storage mode: the key lives server side in an option, and the verification file is served virtually. No alternative modes exist.

A3. Show exactly ONE state of the submissions log. Do not render a populated table and an empty state on the same page. This screen shows the POPULATED state with about six realistic rows. The empty state is not part of this screen.

A4. Do not invent features. There is no retry queue, no scheduling, no cron, no bulk submission, no per post type or per taxonomy selection, no "engine attribution" line, no sitemap submission, and no third party branding. Specifically do NOT add a "Powered by" line, a vendor or company name, a version string in the footer, or a link to an external SEO brand.

A5. Automatic submission is a SINGLE on or off toggle for the whole site. Do not design separate checkboxes for posts, pages, categories, or tags.

A6. Engines are plural. Do not write copy naming only Bing. Say "participating search engines" or name the group generally.

SECTION B: DESIGN SYSTEM, MATCH THE EXISTING PAGES EXACTLY.
- Fonts: Inter for UI text. JetBrains Mono for URLs, HTTP status codes, and timestamps.
- Icons: Material Symbols Outlined, outlined, weight 450, optical size 20.
- Page background #F0F2F5. Cards #FFFFFF. Borders #E2E8F0, stronger #CBD5E1.
- Primary #2563EB, hover #1D4ED8, active #1E40AF, soft tint #EFF6FF.
- Positive #0F766E, soft #F0FDFA. Warning #EA580C, soft #FFF7ED. Error #DC2626, soft #FEF2F2.
- Text #1E293B primary, #475569 secondary, #64748B muted, #94A3B8 hint.
- Radius 4px small, 6px medium, 8px large. Shadow 0 1px 3px rgba(15,23,42,.05).
- Content capped at 1240px, centered, 32px page padding, 8px vertical rhythm.
- Card: white, 1px #E2E8F0 border, 8px radius, soft shadow, 24px padding, bold 15px title.
- Buttons: primary solid #2563EB white semibold 6px radius. Secondary white with #CBD5E1 border. Destructive text button #DC2626.
- Pills: rounded full, 12px semibold, soft background with a matching darker foreground and a 1px border of the same hue.
- Table: 12px text, muted uppercase headers, 1px #E2E8F0 row separators, subtle #F8FAFC row hover, URLs always in JetBrains Mono.
- Notice banner: 4px left border in the semantic color, soft tinted background, leading Material icon, 14px medium text, dismiss close icon on the right.

- Under the title, one muted line: "Notify participating search engines when a URL changes, using the IndexNow protocol."
- Right side: primary button "Submit a URL" with a send icon, and a secondary icon button for settings.

2. ONE NOTICE BANNER only.
- Success style, teal left border: "Settings saved."

3. ROW ONE, two columns, left 60 percent and right 40 percent.
LEFT, card "Automatic submission":
- A single toggle row, currently ON, labelled "Submit URLs automatically when a post or term changes."

6. FOOTER STRIP, full width, quiet.
- One card with three compact facts, each a small icon plus one line: "Only changed URLs are sent", "Sitemaps still handle full coverage", "No data is sent anywhere else".

SECTION D: VISUAL NOTES.
- Calm, dense but breathable, modern SaaS admin that still belongs in WordPress admin.
- Use whitespace and alignment for separation, not heavy fills or borders.
- Status is always a pill with a label, never color alone.
- All URLs and status codes are monospace.
- Copy is factual and concise, sentence case, no marketing language, no exclamation marks.
- Even row heights in the table. No ragged wrapping in the Message column.

DELIVER one desktop page at 1440px wide, full page top to bottom, populated state, key configured, automatic submission on, six rows in the submissions table.
