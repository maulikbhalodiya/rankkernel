AI crawler policy

Training crawlers, AI search crawlers and user triggered fetchers are separate. Blocking a training crawler does not remove you from search. Blocking an AI search crawler removes you from that assistant results.

SECTION 6 OF 8

llms.txt

A curated index for AI tools, served virtually as Markdown with an X-Robots-Tag noindex header. Google Search ignores llms.txt, so this is optional.

info How to make llms.txt

Write a one line summary, then a few sections as Markdown. Each item is a link in the form - [Title](https://example.com/page): one line of context. Keep it short and put your most important pages first, not every post.

Serve the virtual llms.txt route

Rendered as a blockquote under the site name.

Use Markdown headings and link lists, for example a ## Company heading, then a line such as - [About](https://example.com/about): one line of context.

Allow writing a physical llms.txt

The virtual route stays the default. Writing never overwrites an existing file.

Asks for confirmation.

Preview

# Acme Corp
> RankKernel SEO Suite documentation and authoritative product knowledge base.
## Company
- [About](https://example.com/about): Fast, bloat-free WordPress SEO engine.
- [Security](https://example.com/security): Security verification and zero runtime overhead guarantees.

.htaccess

error Danger

A mistake here can take the whole site down, including wp-admin, with no way back into the dashboard. Have file or server access ready before you save. RankKernel writes a timestamped backup next to the file first.

File path: /var/www/html/.htaccess

OTHER STATES THIS SCREEN CAN SHOW
info
Saved.

warning
Not saved.

This server does not read .htaccess.

error
Not saved.

The file could not be written.

warning
Not available on this server

Only Apache and LiteSpeed read .htaccess. This server does not look like either, so the editor is disabled here.

warning
File not writable

WordPress cannot write the .htaccess file. Ask your host, or edit it over SFTP.

When either shows, the path hint, textarea and Save button are omitted entirely.
